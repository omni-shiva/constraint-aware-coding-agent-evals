# Source provenance

This project was created in a new standalone directory for public portfolio use.

All implementation code, documentation, fixtures, tests, scenario text, candidate programs, probe cases, and result formats were authored specifically for this repository. No production repository, employer artifact, client artifact, benchmark submission, or private version-control history was copied into it.

The project uses only Python's standard library at runtime. The MIT license text is the standard license grant included in this repository.
